# Simpleplay

Todos tus juegos —de emulador y de PC— en un solo lugar, listos para jugar con mando.

Este repositorio sólo guarda los **instaladores** de cada versión. Descarga el último
`Simpleplay-Setup-x.y.z.exe` de [Releases](../../releases/latest) e instálalo; a partir de ahí
Simpleplay se actualiza solo (busca versiones nuevas al abrirse y las instala al cerrarse).

- Windows 10/11 de 64 bits.
- Simpleplay **no incluye emuladores ni juegos**: encuentra los que ya tengas en tus discos
  (y tus juegos de Steam y Epic).
- No está firmado: Windows SmartScreen puede avisar al instalar
  («Más información › Ejecutar de todas formas»).
